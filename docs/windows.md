# Запуск на Windows

Компьютер будет передавать ваши видео на телевизор. Подключите оба устройства
к одной домашней сети.

## 1. Установите Docker Desktop

Скачайте [Docker Desktop для Windows](https://docs.docker.com/desktop/setup/install/windows-install/)
— вариант **x86_64** для обычного компьютера с Intel или AMD. Запустите установщик,
оставьте рекомендуемые настройки и **WSL 2**. Если потребуется, перезагрузите компьютер.
Откройте Docker Desktop через «Пуск» и дождитесь запуска. Если предлагается вход
в аккаунт, его можно пропустить.

## 2. Скачайте и запустите MSX Channels

[Скачайте ZIP](https://github.com/dexogen/msx-channels/archive/refs/heads/main.zip),
нажмите правой кнопкой → **Извлечь всё**. Откройте распакованную папку,
в которой находится `compose.yaml`.

Нажмите на адресную строку Проводника, введите `powershell` и нажмите Enter.
В открывшееся окно скопируйте эти три строки и нажмите Enter:

```powershell
mkdir videos
Copy-Item .env.example .env
notepad .env
```

В Блокноте найдите `ADMIN_PASSWORD=` и впишите после `=` свой пароль:
не менее 12 латинских букв и цифр, без пробелов. Сохраните (**Ctrl+S**) и закройте
Блокнот. Вернитесь в PowerShell и выполните:

```powershell
docker compose -p msx-channels up -d
```

Первый запуск займёт несколько минут. В Docker Desktop → **Containers**
появится `msx-channels`. Если Windows спросит о доступе Docker к сети,
разрешите его для вашей **частной домашней сети**.

## 3. Добавьте видео

Откройте на компьютере [админку](http://localhost:8080/admin).
Логин — **admin**, пароль — тот, который вы только что задали.

Нажмите **Загрузить видео**, выберите ролик и дождитесь статуса **Готово**.
Затем **Создать канал** → название → видео → **Сохранить**. Для начала подойдёт MP4.

## 4. Подключите телевизор

1. На телевизоре откройте магазин приложений, найдите и установите
   **[Media Station X](https://msx.benzac.de/wiki/index.php?title=Setup_Start_Parameter)**.
2. На компьютере откройте **Параметры → Сеть и Интернет** → свойства активного
   Wi-Fi или Ethernet. Найдите **IPv4-адрес**, например `192.168.1.50`.
3. В Media Station X откройте **Settings → Start Parameter → Setup**.
   Введите **свой адрес с `:8080`**, например `192.168.1.50:8080`.
   Замок HTTPS должен быть выключен. Подтвердите — появится меню ваших каналов.

`localhost` работает только на компьютере. Для телефона и телевизора используйте
его сетевой адрес; например, админка на телефоне — `http://192.168.1.50:8080/admin`.

**На каждый день:** оставляйте компьютер включённым, без сна, и Docker Desktop
запущенным. Остановить или включить сервис можно кнопками **Stop / Start** рядом
с `msx-channels` в разделе **Containers**. Заменять ролик можно через **Изменить**
в админке — адрес канала сохранится.
