# Запуск на macOS

Mac будет передавать ваши видео на телевизор. Подключите оба устройства
к одной домашней сети.

## 1. Установите Docker Desktop

Скачайте [Docker Desktop для Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
Выберите **Apple silicon**, если в меню ** → Об этом Mac** указан чип Apple M1,
M2 и т. п.; для процессора Intel — **Intel chip**.

Откройте скачанный `.dmg`, перетащите Docker в **Программы** и запустите его
оттуда. Выберите рекомендуемые настройки, подтвердите запрошенные разрешения
и дождитесь запуска. Если предлагается вход в аккаунт, его можно пропустить.

## 2. Скачайте и запустите MSX Channels

[Скачайте ZIP](https://github.com/dexogen/msx-channels/archive/refs/heads/main.zip)
и распакуйте двойным щелчком, если браузер ещё не сделал это. Найдите папку
с файлом `compose.yaml`.

Откройте **Терминал** через поиск **⌘+Пробел**. Напечатайте `cd ` с пробелом,
перетащите эту папку из Finder в окно Терминала и нажмите Enter.
Скопируйте туда следующие строки и нажмите Enter:

```sh
mkdir -p videos
cp .env.example .env
open -e .env
```

В открывшемся редакторе найдите `ADMIN_PASSWORD=` и впишите после `=` свой пароль:
не менее 12 латинских букв и цифр, без пробелов. Сохраните (**⌘+S**) и закройте
файл. Вернитесь в Терминал и выполните:

```sh
docker compose -p msx-channels up -d
```

Первый запуск займёт несколько минут. В Docker Desktop → **Containers**
появится `msx-channels`. Версия для Intel или Apple M выбирается автоматически.

## 3. Добавьте видео

Откройте на Mac [админку](http://localhost:8080/admin).
Логин — **admin**, пароль — тот, который вы только что задали.

Нажмите **Загрузить видео**, выберите ролик и дождитесь статуса **Готово**.
Затем **Создать канал** → название → видео → **Сохранить**. Для начала подойдёт MP4.

## 4. Подключите телевизор

1. На телевизоре откройте магазин приложений, найдите и установите
   **[Media Station X](https://msx.benzac.de/wiki/index.php?title=Setup_Start_Parameter)**.
2. На Mac откройте **Системные настройки → Сеть** → активное подключение
   **Wi-Fi / Ethernet → Подробнее → TCP/IP**. Найдите **IP-адрес**, например `192.168.1.50`.
3. В Media Station X откройте **Settings → Start Parameter → Setup**.
   Введите **свой адрес с `:8080`**, например `192.168.1.50:8080`.
   Замок HTTPS должен быть выключен. Подтвердите — появится меню ваших каналов.

`localhost` работает только на Mac. Для телефона и телевизора используйте
его сетевой адрес; например, админка на телефоне — `http://192.168.1.50:8080/admin`.

**На каждый день:** оставляйте Mac включённым, без сна, и Docker Desktop
запущенным. Остановить или включить сервис можно кнопками **Stop / Start** рядом
с `msx-channels` в разделе **Containers**. Заменять ролик можно через **Изменить**
в админке — адрес канала сохранится.
